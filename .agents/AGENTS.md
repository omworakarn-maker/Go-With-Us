# Agent Rules

## Git Operations (Frontend)
- **DO NOT** run `git push` automatically after modifying frontend code (e.g., SwiftUI files, UI components).
- You may run `git add` and `git commit` to save the work locally, but you must stop and allow the USER to manually run `git push` when they are ready.

## Strict Adherence to Instructions
- **Do NOT make proactive changes**: Never modify code, change designs (colors, UI, layout), or refactor existing code unless the user explicitly requests it.
- **Answer without editing**: If the user asks a theoretical or exploratory question (e.g., "Why does this look dull?", "How does this work?"), provide an explanation or answer **WITHOUT** making any code changes.
- **Stick strictly to the requested scope**: If tasked with fixing a specific line or component, do not modify unrelated files or components "just to make it better."
