# GoWithUs - Notification System

ระบบแจ้งเตือน (Notifications) สำหรับโปรเจกต์ GoWithUs รองรับทั้งการประกาศข่าวสารทั่วไป (Public) และการแจ้งเตือนส่วนบุคคล (Private)

## 🛡️ ระบบรักษาความปลอดภัย (Security)

เพื่อให้ระบบมีความปลอดภัยสูงสุด เราได้วางระบบป้องกันไว้ 2 ชั้น:
1.  **Frontend Protection:** หน้าจัดการการแจ้งเตือน (`/admin-alert`) จะถูกล็อคไว้ให้เฉพาะผู้ใช้ที่มี Role เป็น `admin` เท่านั้นที่เข้าได้ หากผู้ใช้ทั่วไปพยายามเข้าถึง ระบบจะ Redirect กลับไปหน้าหลักทันที
2.  **Backend Verification:** ทุกคำขอที่ส่งไปยัง API สำหรับสร้างการแจ้งเตือน จะถูกตรวจสอบสิทธิ์ (RBAC) ที่ฝั่ง Server เสมอ เพื่อป้องกันการส่งข้อมูลปลอมผ่านเครื่องมืออื่นๆ

## 💻 วิธีการส่งการแจ้งเตือนผ่าน VS Code (CLI)

คุณสามารถส่งข้อความแจ้งเตือนหาทุกคนในระบบได้โดยตรงจาก Terminal ของ VS Code โดยไม่ต้องเปิดหน้าเว็บ

### คำสั่งหลัก:
```bash
# พิมพ์ในโฟลเดอร์ go-with-us-backend
npm run send-noti "<หัวข้อ>" "<ข้อความ>"
```

### ตัวอย่างการใช้งาน:

**1. ส่งประกาศทั่วไป (Public Alert):**
```bash
npm run send-noti "อัปเดตระบบ" "ทีมงานจะทำการปิดปรับปรุงระบบในเวลา 02:00 น."
```

**2. ส่งแจ้งเตือนเกี่ยวกับทริป (Trip Notification):**
```bash
# รูปแบบ: npm run send-noti "<หัวข้อ>" "<ข้อความ>" <ประเภท>
npm run send-noti "ทริปใหม่!" "มีสมาชิกเพิ่มทริปใหม่ที่น่าสนใจสำหรับคุณ" trip
```

**3. คำสั่งลบ (Delete):**
```bash
# ลบทีละรายการด้วย ID
npm run del-noti <id>
```
# ลบทั้งหมดของประเภทนั้นๆ (alert, trip, system)
npm run del-noti type trip

# ลบแจ้งเตือนทั้งหมดในระบบ (ต้องยืนยันตัวตน)
npm run del-noti all
```

### รายละเอียด Argument:
| Argument | คำอธิบาย | ข้อมูลเพิ่มเติม |
| :--- | :--- | :--- |
| `title` | หัวข้อแจ้งเตือน | **จำเป็นต้องใส่** |
| `message` | รายละเอียดข้อความ | ใส่ได้ตามต้องการ (Optional) |
| `type` | ประเภทการแจ้งเตือน | `alert` (ค่าเริ่มต้น), `trip`, `system` |
| `userId` | ID ผู้รับ | หากระบุจะส่งหาคนนั้นคนเดียว ถ้าไม่ระบุจะ**ส่งหาทุกคน** |

## 🎨 การปรับแต่งดีไซน์ (Customization)

ระบบแจ้งเตือนปัจจุบันถูกปรับให้เป็น **Monochrome Style (ขาว-ดำ-เทา)** เพื่อความคลีนและหรูหรา:
- รายการที่ยังไม่ได้อ่านจะแสดง **จุดสีแดงเล็กๆ** เพื่อความชัดเจน
- ไอคอนเป็นแบบ SVG ขาวดำ (📢, 🗺️, ⚙️)
- ไม่มีพื้นหลังสีฟ้าในรายการที่ยังไม่ได้อ่านแล้ว
