# Repository Instructions

Read and follow the existing project rules in [.agents/AGENTS.md](.agents/AGENTS.md) before working in this repository.

## Extended description for commits and pushes

- ทุกครั้งก่อน commit หรือ push ต้องเขียน Extended description เป็นภาษาอังกฤษ อธิบายสิ่งที่เปลี่ยน เหตุผล และผลการทดสอบ ใส่เป็น commit body และแสดงให้ผู้ใช้อ่านด้วย
- Before every commit or push, prepare an English Extended description covering what changed, why it changed, and the actual validation results. Include it in the commit body and show it to the user.
- Report checks that were not run or limitations honestly; do not claim unperformed testing.
- For pushes of existing commits, verify that the relevant commit bodies contain the Extended description. Do not rewrite published history without explicit user authorization.
