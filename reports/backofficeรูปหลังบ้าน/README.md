# ภาพประกอบระบบหลังบ้าน GoWithUs

## 1. BackofficeDashboard.png — หน้าภาพรวมระบบ

แสดงข้อมูลสรุปที่สำคัญสำหรับผู้ดูแลระบบ ได้แก่ จำนวนผู้ใช้ทั้งหมด จำนวนทริปทั้งหมด คำขอยืนยันตัวตน รายงานที่รอตรวจสอบ บัญชีที่ยืนยันแล้ว และบัญชีที่ถูกระงับ นอกจากนี้ยังมีส่วนงานที่ควรตรวจสอบเพื่อให้ผู้ดูแลเข้าถึงงานเร่งด่วนได้จากหน้าเดียว

## 2. BackofficeUsers.png — หน้าจัดการผู้ใช้

ใช้ค้นหาและตรวจสอบบัญชีผู้ใช้ โดยแสดงชื่อ อีเมล สถานะ จำนวนทริปที่สร้าง จำนวนทริปที่เข้าร่วม จำนวนรายงาน และวันที่สมัคร ผู้ดูแลระบบสามารถกรองตามสถานะและระงับบัญชีที่ไม่ปฏิบัติตามข้อกำหนดของระบบได้

## 3. BackofficeTrips.png — หน้าจัดการทริป

ใช้ค้นหาและตรวจสอบทริปจากชื่อทริป สถานที่ ผู้สร้าง หรือหมวดหมู่ แต่ละรายการแสดงชื่อ สถานที่ ผู้สร้าง จำนวนสมาชิก วันเริ่มต้น งบประมาณ และประเภททริป ผู้ดูแลสามารถเปิดดูรายละเอียดหรือลบทริปที่ไม่เหมาะสมได้

## 4. BackofficeReport.png — หน้าจัดการรายงานผู้ใช้

แสดงรายการรายงานบัญชีที่ผู้ใช้ส่งเข้ามาเพื่อให้ผู้ดูแลตรวจสอบ ในภาพยังไม่มีรายงานที่รอดำเนินการ จึงแสดงสถานะว่างของระบบ

## 5. BackofficeVerified.png — หน้าตรวจสอบการยืนยันตัวตน

ใช้ตรวจสอบคำขอยืนยันตัวตนโดยเปรียบเทียบบัตรประจำตัวประชาชนกับภาพใบหน้าของผู้ใช้งาน ในภาพยังไม่มีคำขอที่รอการตรวจสอบ

## 6. BackofficeNoti.png — หน้าจัดการการแจ้งเตือน

แบ่งเป็นส่วนสร้างการแจ้งเตือนใหม่และรายการแจ้งเตือนทั้งหมด ผู้ดูแลสามารถกำหนดหัวข้อ ข้อความ และประเภทการแจ้งเตือน ได้แก่ ทั่วไป ทริป หรือระบบ รวมถึงล้างรายการแจ้งเตือนทั้งหมดได้
