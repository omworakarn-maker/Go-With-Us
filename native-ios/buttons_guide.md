# คู่มืออธิบายการทำงานของปุ่มและองค์ประกอบที่โต้ตอบได้ใน SwiftUI Views (GoWithUs)

คู่มือฉบับนี้อธิบายการทำงานขององค์ประกอบโต้ตอบได้ (Interactive Elements) เช่น Button, NavigationLink, onTapGesture, Swipe Actions และอื่นๆ ในไฟล์ View ต่างๆ ภายในโฟลเดอร์ `Views` และโฟลเดอร์ย่อย ของโปรเจกต์ GoWithUs อย่างละเอียด 

---

## 1. หน้าจอหลัก (Home)

### **HomeView** (หน้าจอหลักแบบรายการ) & **HomeGridView** (หน้าจอหลักแบบกริด)
*   **ปุ่ม Menu (ไอคอน 3 ขีด):** แตะเพื่อสลับการแสดงผลของเมนูด้านข้าง (Side Menu) โดยระบบจะสลับค่า (Toggle) ตัวแปร `showSideMenu` และเพิ่มเอฟเฟกต์การสั่น (Haptic) 
*   **ปุ่ม Layout Switcher (ไอคอน Grid/List):** แตะเพื่อสลับรูปแบบการแสดงผลหน้าหลักระหว่างแบบกริดและแบบรายการ ระบบจะอัปเดตการตั้งค่าใน `SettingsManager` และแสดงแอนิเมชันตอนสลับ 
*   **ปุ่ม Notification Bell (ไอคอนกระดิ่ง):** แตะเพื่อเปิดหน้าต่างป๊อปอัปแจ้งเตือน (เปลี่ยนตัวแปร `showNotifications` เป็น true เพื่อแสดง `NotificationView` รูปแบบ Sheet) 
*   **ปุ่มล้างการค้นหา (ไอคอนกากบาท X ใน Search Bar):** จะแสดงขึ้นเมื่อมีการพิมพ์ข้อความค้นหา แตะเพื่อล้างข้อความในช่องค้นหา (`viewModel.searchText = ""`) และยกเลิกโฟกัสแป้นพิมพ์
*   **NavigationLink บนการ์ดทริป (TripCardView / TripGridCardView):** เมื่อแตะที่การ์ดของทริป ระบบจะนำทางผู้ใช้ไปยังหน้า `TripDetailView(tripId: trip.id)` เพื่อดูรายละเอียดแบบเต็มของทริปนั้นๆ
*   **พื้นที่ว่างของหน้าจอ (onTapGesture):** เมื่อแตะที่พื้นที่ว่าง (Background) ระบบจะยกเลิกการโฟกัสช่องค้นหา (ปิดคีย์บอร์ด)
*   **ปุ่ม "ลองใหม่" (Retry):** หากโหลดข้อมูลไม่ได้ ระบบจะแสดงปุ่มนี้เพื่อให้ลองเรียกฟังก์ชันดึงข้อมูลทริปอีกครั้ง (`await viewModel.loadTrips()`)

## 2. ระบบยืนยันตัวตน (Auth)

### **LoginView** (หน้าเข้าสู่ระบบ)
*   **ปุ่ม "เข้าสู่ระบบ":** แตะเพื่อล็อกอินเข้าสู่แอปพลิเคชัน จะเรียกฟังก์ชัน `await viewModel.login()` 
*   **NavigationLink "สมัครสมาชิก":** แตะเพื่อนำทางไปยังหน้า `RegisterView` 
*   **พื้นที่ว่าง (onTapGesture):** แตะเพื่อซ่อนแป้นพิมพ์ (`hideKeyboard()`)

### **RegisterView** (หน้าสมัครสมาชิก)
*   **ปุ่มย้อนกลับ (ไอคอนลูกศรซ้าย):** แตะเพื่อกลับไปยังหน้าก่อนหน้า (`dismiss()`)
*   **ปุ่มรูปตา (แสดง/ซ่อนรหัสผ่าน):** แตะเพื่อสลับการมองเห็นข้อความรหัสผ่าน (`showPassword.toggle()` และ `showConfirmPassword.toggle()`)
*   **ปุ่ม "สมัครสมาชิก":** แตะเพื่อส่งข้อมูลสมัครสมาชิก โดยจะเรียกการประมวลผลผ่าน `await viewModel.register()`
*   **พื้นที่ว่าง (onTapGesture):** แตะเพื่อซ่อนแป้นพิมพ์

### **OTPVerificationView** (หน้ายืนยันรหัส OTP)
*   **ปุ่ม "ยืนยันรหัส":** ใช้ตรวจสอบรหัส OTP ระบบจะเรียกฟังก์ชัน `verifyOTP()` หากสำเร็จจะปิดหน้าจอนี้ไป (`dismiss()`)
*   **ปุ่ม "ส่งรหัสใหม่" (Resend Button):** หากเวลานับถอยหลังหมดลง ผู้ใช้สามารถกดเพื่อขอรหัส OTP ใหม่ได้ (`await viewModel.resendOTP()`)

## 3. ระบบแจ้งเตือน (Notification)

### **NotificationView**
*   **ปุ่ม "ลบทั้งหมด" (Clear All):** แสดงอยู่ที่มุมซ้ายบน (ถ้ามีการแจ้งเตือน) แตะเพื่อลบประวัติการแจ้งเตือนทั้งหมด (`await viewModel.clearAllNotifications()`)
*   **ปุ่ม "ปิด" (Close):** มุมขวาบน แตะเพื่อปิดหน้าต่างแจ้งเตือนและกลับไปยังหน้าหลัก (`dismiss()`)
*   **NotificationRow (ปุ่มของแต่ละการแจ้งเตือน):** เมื่อแตะที่การแจ้งเตือนรายการใดรายการหนึ่ง ระบบจะทำเครื่องหมายว่าอ่านแล้ว (Mark as read) ทันที ผ่าน `await viewModel.markAsRead(id:)`
*   **Swipe Actions (ปัดที่รายการ):** ปัดที่การแจ้งเตือนเพื่อเปิดเมนู "ลบ" และกดยืนยันเพื่อลบการแจ้งเตือนนั้นออกไป (`await viewModel.deleteNotification(id:)`)

### **AdminAlertView**
*   **ปุ่ม "ยกเลิก":** ยกเลิกการสร้างแจ้งเตือนและปิดหน้าต่าง (`dismiss()`)
*   **ปุ่ม "ส่งการแจ้งเตือน":** เรียกฟังก์ชันสร้างการแจ้งเตือนไปยังผู้ใช้ระบบ (`await viewModel.createAlert()`)

## 4. แมตช์ทริปและหาเพื่อน (MatchTrip & FindBuddy)

### **MatchTripView** (หน้าปัดหาทริป)
*   **ปุ่ม Menu (ไอคอน 3 ขีด):** สลับการแสดงเมนูด้านข้าง
*   **ปุ่มรีเฟรช (ลูกศรหมุน):** โหลดหารายการทริปใหม่แบบสุ่ม (`await viewModel.fetchMatches()`)
*   **ปุ่ม "ลองใหม่":** ปุ่มสำหรับกรณีโหลดข้อผิดพลาดเพื่อรีโหลดข้อมูล
*   **TinderSwipeCardView (การ์ดทริป):**
    *   **DragGesture ปัดขวา:** แจ้งว่าเราสนใจเข้าร่วมทริปนี้ และระบบจะนำทางไปยังหน้ารายละเอียดทริปเพื่อเข้าร่วม
    *   **DragGesture ปัดซ้าย:** เลื่อนผ่าน/ปัดทิ้ง ระบบจะนำการ์ดนี้ออกจากลิสต์ (`matches.removeAll`)
    *   **onTapGesture บนการ์ด:** แตะเพื่อนำทาง (NavigationDestination) ไปเปิดดูรายละเอียดทริปแบบเต็ม 

### **FindBuddyView** (หน้าปัดหาเพื่อน)
*   **ปุ่ม Menu:** สลับการแสดงเมนูด้านข้าง
*   **ปุ่มรีเฟรช (ลูกศรหมุน):** ดึงข้อมูลผู้ใช้ที่ตรงกับความสนใจรายใหม่
*   **ปุ่มแสดง Mutual Matches (ไอคอนแชทมุมขวาบน):** แตะเพื่อเปิดหน้าเพื่อนที่คุณแมตช์ด้วยกันสำเร็จผ่าน Sheet `MutualMatchesView`
*   **BuddySwipeCard (การ์ดโปรไฟล์เพื่อน):**
    *   **DragGesture ปัดขวา:** กด Like หากสนใจอยากไปเที่ยวกับบัดดี้คนนี้
    *   **DragGesture ปัดซ้าย:** ปัดซ้าย (Nope) เพื่อเลื่อนผ่าน
    *   **onTapGesture ซ้าย/ขวาของหน้าจอ:** ใช้สำหรับสลับดูรูปภาพโปรไฟล์/รูปแกลเลอรีต่างๆ (เปลี่ยนตัวแปร `currentImageIndex`)
*   **ปุ่ม "เริ่มคุยกันเลย!":** อยู่ในหน้าต่างฉลองเมื่อทั้งสองฝ่ายกดไลก์กันและกัน ปิดหน้าจอเพื่อให้สามารถไปที่หน้าแชทต่อได้
*   **ปุ่ม "ปัดหาเพื่อนต่อ":** ปิดหน้าต่าง Match เพื่อเลื่อนหาเพื่อนต่อ

### **MutualMatchesView** (หน้าเพื่อนที่แมตช์สำเร็จ)
*   **NavigationLink ไปหน้าแชท:** เมื่อกดที่โปรไฟล์คนที่แมตช์ด้วย จะพาไปเปิดห้องสนทนาส่วนตัว (`ChatDetailView`)

## 5. ทริปของฉันและสร้างทริป (My Trips & Create Trip)

### **MyTripsView** (หน้าทริปของฉัน)
*   **ปุ่ม Menu:** สลับการแสดงเมนูด้านข้าง
*   **Picker (Segmented Control):** แตะเพื่อสลับการแสดงผลหมวดหมู่ทริปผ่านค่า `selectedTab` (สร้างเอง, เข้าร่วมแล้ว, รายการโปรด)
*   **NavigationLink "สร้างทริป":** เมื่อยังไม่มีการสร้างทริป จะมีปุ่มพาไปหน้า `CreateTripView`
*   **NavigationLink ที่ตัวทริป:** แตะการ์ดทริปใดทริปหนึ่งเพื่อเปิด `TripDetailView`

### **CreateTripView** (หน้าสร้างหรือแก้ไขทริป)
*   **ปุ่ม "ยกเลิก":** ยกเลิกการสร้าง/แก้ไขและปิด Sheet (`dismiss()`)
*   **ปุ่ม "ลบ" (ถังขยะ) (กรณีแก้ไขเท่านั้น):** แตะเพื่อลบทริป พร้อมแสดง Alert ให้กดยืนยันการลบ
*   **Dropdown เมนูจังหวัด/หมวดหมู่:** แตะเพื่อคลี่เมนูรายการตัวเลือก
*   **ปุ่ม "เพิ่มหมวดหมู่...":** เปิด Sheet ใหม่อีกชั้นเพื่อให้ผู้ใช้พิมพ์ชื่อหมวดหมู่เอง
*   **ปุ่ม Toggle "สาธารณะ":** สวิตช์สำหรับตั้งค่า `isPublic` ว่าจะให้ใครเห็นได้บ้าง
*   **ปุ่มบวกในส่วนของ Tag / คีย์เวิร์ด:** แตะปุ่มบวก (+) หรือกด Return ในแป้นพิมพ์เพื่อเพิ่มคีย์เวิร์ดเข้าสู่อาร์เรย์ `tags`
*   **ปุ่มลบ (X) บน Tag:** แตะที่ป้าย Tag เพื่อลบมันออกจาก `tags`
*   **Slider (สไตล์กิจกรรม):** เลื่อนปรับเปอร์เซ็นต์ว่าอยากเน้นพักผ่อนสบายๆ หรือลุยหนักๆ (1 ถึง 10)
*   **ปุ่ม "ช่วงเวลาของทริป":** แตะที่ช่วงเวลา (เช้า, กลางวัน, เย็น, ดึก) เพื่อเปิด-ปิดการเลือกแบบหลายตัวเลือก
*   **ปุ่ม "AI ช่วยจัดทริป" (ไอคอน Sparkles):** แตะเพื่อเรียกใช้งานฟังก์ชัน `generateAITrip()` สั่งให้ Gemini สร้างตารางเดินทาง
*   **ปุ่ม "สร้างทริป" หรือ "บันทึกการแก้ไข":** กดยืนยันเพื่อบันทึกข้อมูลและอัปโหลดไปที่ API 

### **TripDetailView** (หน้ารายละเอียดทริป)
*   **ปุ่ม "สนใจ" (Interested - รูปดาว):** สำหรับผู้ใช้ที่แค่เล็งทริปนี้ไว้แต่ยังไม่ยืนยันว่าจะไป เมื่อกดจะเปิดหน้าต่างยืนยันความสนใจ สถานะในทริปจะกลายเป็น "interested" (แค่แสดงความสนใจในทริป ยังไม่หักโควตาที่นั่งและยังไม่ถือว่าเป็นลูกทริปเต็มตัว)
*   **ปุ่ม "จะไปด้วย" (Will Go - รูปคนบวก):** สำหรับผู้ใช้ที่ตัดสินใจจะเข้าร่วมทริปแน่นอน เมื่อกดจะเข้าสู่หน้าต่างยืนยันการเข้าร่วม (Join Flow) สถานะจะกลายเป็น "going" หรือ "joined" ทันที ระบบจะบันทึกให้คุณเป็นลูกทริปอย่างเป็นทางการพร้อมหักโควตาจำนวนที่นั่งว่างในทริปนั้นลง

## 6. ข้อความและการพูดคุย (Chat)

### **ChatView** (หน้าแสดงรายการแชทหลัก)
*   **ปุ่มรูปเพื่อนใหม่ (Mutual Matches ด้านบน):** แตะที่วงกลมอวตารเพื่อนใหม่เพื่อสร้างการนำทางไปยังห้องแชท
*   **ปุ่มกดของแต่ละบทสนทนา (ConversationRow):** แตะที่ห้องสนทนาเพื่อนำทางไปที่ `ChatDetailView` ของแชทนั้น
*   **Swipe Action "ลบ":** ปัดซ้ายที่รายการแชทเพื่อลบประวัติการสนทนาห้องนั้นๆ ทิ้ง (`viewModel.deleteConversation`)

### **ChatDetailView** (หน้าต่างในห้องแชท)
*   **ปุ่ม "ย้อนกลับ" (Chevron Left):** กลับไปยังหน้ารายการแชทหลัก (`dismiss()`)
*   **ปุ่มกดที่ชื่อ/รูปโปรไฟล์คู่สนทนา (Header ด้านบน) & ปุ่มวงกลมไอคอนโปรไฟล์มุมขวา:** แตะเพื่อดึงข้อมูลผ่าน Sheet และเปิดหน้า `UserProfileView` ของผู้สนทนา
*   **onTapGesture บนรูปภาพอวตารในแชท (MessageBubble):** เมื่อแตะที่รูปโปรไฟล์ของคนในแชท จะเปิดหน้าโปรไฟล์ส่วนตัวของเขาทันที
*   **เมนู Context (กดค้างที่ข้อความแชท):**
    *   "คัดลอกข้อความ": เพื่อก๊อปปี้ข้อความลง Clipboard (`UIPasteboard.general.string`)
    *   "ยกเลิกข้อความ" (สำหรับข้อความของเราเอง): สั่งลบข้อความออก (`await viewModel.deleteMessage(message)`)
*   **ปุ่ม "+" (PhotosPicker):** เปิด Photo Library เพื่อเลือกรูปภาพ
*   **ปุ่มลบ (X) รูปภาพที่เลือกมา:** กดเพื่อยกเลิกรูปที่เพิ่งเลือกมา
*   **ปุ่ม "ลูกศรขึ้น" (ส่งข้อความ):** แตะเพื่อส่งข้อความตัวอักษรและ/หรือรูปภาพ (`await sendMessage()`)

### **AIChatView** (ผู้ช่วย AI)
*   **ปุ่ม Menu:** สลับการแสดงเมนูด้านข้าง
*   **ปุ่มลบแชท (ถังขยะมุมขวาบน):** ล้างประวัติการคุยกับ AI ทั้งหมด (`viewModel.clearChat()`)
*   **ปุ่ม "ปรับแก้ก่อนสร้าง":** หาก AI ร่างทริปให้เสร็จ (TripDraft) จะมีปุ่มนี้นำทางไปเปิดหน้า `CreateTripView` เพื่อให้ผู้ใช้แก้ไขเพิ่มเติม
*   **ปุ่ม "สร้างเลย":** กดปุ่มนี้เพื่อยิง API สร้างทริปอัตโนมัติจากร่างของ AI ทันที (`autoCreateTrip(draft: draft)`)
*   **ปุ่ม "ลูกศรขึ้น" (ส่ง):** ส่งข้อความ/Prompt ให้ Gemini AI ประมวลผล (`await viewModel.sendMessage()`)
